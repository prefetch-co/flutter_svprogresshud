When the user tells me to start implementing a Jira issue, if the issue is in the Backlog or To Do column, move it to the In Progress column.

**Why:** User instruction.

**How to apply:** On "start implement" for a Jira issue — check its status; Backlog or To Do → transition to In Progress. Related: [[feedback_jira_issue_description_english]]
